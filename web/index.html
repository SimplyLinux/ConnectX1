Installation Guide
1
Download and extract the ZIP file from the link above.
2
Move ConnectX1.app to your /Applications folder.
3
Open Terminal and run the quarantine removal command:

sudo xattr -rd com.apple.quarantine /Applications/ConnectX1.app

This is needed because we don't yet have an Apple Developer certificate — macOS blocks unsigned apps by default. This command removes the quarantine flag safely.
4
Launch ConnectX1 from Applications or Spotlight.
1
Download the installer (.exe file) from the link above.
2
Run the installer by double-clicking it.
3
You may see a Windows SmartScreen warning. Click "More info" then "Run anyway". This warning appears because the app is not yet certified by Microsoft — it will disappear once we obtain code signing certificates.
4
Follow the on-screen installer steps and launch ConnectX1 from the Start menu.
1
Download the .deb package from the link above.
2
Install using your package manager:

sudo dpkg -i ConnectX1_0.1.1_amd64.deb

Or simply double-click the .deb file to install via your Software Center.
3
Launch ConnectX1 from your application launcher or run connectx1 in terminal.
